# V2 手绘封面规范（当前默认实验风格）

> 本文件只约束 **V2** 封面。V1 旧风格、全集覆盖口径与旧字体要求冻结在 `cover-style.md`，两轨不混用。教材、发布正文、来源准确性、云文档交付流程在 V1/V2 间共享，不在此重复。

## 版本路由

- 新选题默认走 **V2**；只有用户明确指定 V1 才走 V1。不按历史数据自动回切。
- manifest 与 cover-review 都记录 `cover_version: "v2"`；workflow 登记版本，三处一致。历史已完成且未标版本的产物按 V1 兼容只读处理，不认作 V2，不回写旧记录。
- 封面单独修改（cover-edit）必须显式选版，且与已登记 release 版本一致；跨版本重做要新 revision 记录，不允许无声换轨。
- cover-review 的 `cover_files` 中**每个**源/预览条目都记录 `"version": "v2"` 并与 manifest 一致；V1 旧产物不要求该字段（兼容只读）。
- **跨版本重做路线**：换轨不是在旧 release 上 cover-edit。另建独立选题目录，重新 `init`（新选题默认 v2；明确指定才 v1），按该轨重新制作并登记；旧 release 的 manifest/review/hash 归档只读，不被回写。

## 信息结构（四条，按此取舍）

1. **主问题**：顶部一句话点出面试题。顶部第一排就是 L1 大标题，标题上方不留眉题行。
2. **一句核心判断**：有信息量的主张，不是“很重要”“是关键”。
3. **核心结构**：流程主干（输入到关键节点的链路）或框架分区（模块与关系），二选一贴合主题，不硬造另一种。
4. **关键分支**：会改变结论或路径的分支（重试/降级/中止/人工确认等）。

必要收口主题（适用前提、版本条件）本篇没有对应内容就**不造节点、不造参数、不造失败路径**；确需表达的条件见下文「条件承接」。

### 顶部标题：不设眉题

- 顶部第一排就是 L1 主问题大标题；不在大标题上方另起一行放栏目名、系列名、期次编号或主题小标签等眉题（kicker/overline），如“面试总结”“Agent 记忆”“系列第 N 期”“知识卡片”。顶部空间优先留给大标题的字号、换行与手绘下划线，不为眉题压缩标题。
- 不算眉题的情形：主标题本身包含选题主题词（如“面试总结：Agent Memory 怎么设计？”）；中部节点标签/短注里的合法术语（如“记忆”“Memory”）；双页 ①/② 页码标记。
- 文本可编辑源（SVG/HTML）由 `scripts/check_v2_eyebrow.py` 在渲染前做确定性预检：只检大标题上方、字号明显更小且命中栏目/系列/期次标签模式的独立小标签；正文节点术语、HTML/XML 注释与隐藏元素不参与判定。非文本成品（PNG/JPG 等）无法源检时跳过机检，由渲染人工核对，结论写进 style_check 证据，不声称机检通过。

## 视觉

- 背景：暖米白轻纸纹 `#FAF6EE` + 径向渐变颗粒。
- 语义色：琥珀 `#C9762B` 判断/关口；绿 `#2F7A55` 可行路径/事实；红 `#B8382A` 失败/不适用；灰 `#7A736A` 降级/中性。避免无意义多彩和大面积紫色。
- 手绘线条：框线抖动重描两遍、边角略微出头；箭头两笔短线手绘，不用 SVG `<marker>` 规整三角；固定随机种子保证可复现。
- 标题深黑 `#2E2A26`；手绘下划线是**可选**强调手段，按版式空间选用，不强制复刻锚点图中不存在或未出现的装饰元素，也不改动认可图本身。

## 字体（中英均明显手写，配对随技能捆绑）

字体资源在 `assets/fonts/`，清单 `assets/fonts/fonts-manifest.json` 记录家族名、角色、字重、版本、许可、来源 URL 与 sha256；许可件随字体一并保留，跨环境携带同一批字节。`scripts/check_v2_fonts.py` 为 V2-only 检查（V1 不调用）：实读捆绑 cmap、登记字段与哈希一致、回退链合法性、run 拆分零丢字；依赖 fontTools，缺失时明确失败退出，不静默通过。

- **配对**（均 Regular 400，不合成 bold；英文不得粗黑、过大）：
  - 中文主：`LXGW WenKai` v1.530（霞鹜文楷，SIL OFL 1.1）。
  - 英文主：**`Patrick Hand` v1.003，Regular 400（SIL OFL 1.1）**，相对中文 em 系数 **1.03**；默认干净、直立、圆润，不使用伪斜、连写花体或合成粗体。标题、节点英文与数字统一使用它。
  - 英文备：`Caveat` v2.000（wght=400 静态实例，SIL OFL 1.1），相对中文 em 系数 **1.03**；仅保留历史兼容或用户显式选用，不因主字体失败自动换回。确需入回退链时先记录明确选择与 QA。不引入第三套花字体，毛笔标题类备选不捆绑进技能。
  - **固定字样锚点**：`assets/font-anchor-patrick-hand.png`（用户选定第一款“harness 循环”）。该图英文 124px / 中文 120px、共同基线、Regular、绿色与米白底。保留字形、笔画与中英视觉比例，随母版同比放大，不把英文横向压缩。已有封面不自动追溯修改。
- **字阶**（1080×1440 基准，px；更高分辨率按同比例放大，字号/线宽/边距同步）：

  | 层级 | 中文 WenKai | Patrick Hand（默认） | Caveat（显式备选） | 行高 1.32em |
  | --- | --- | --- | --- | --- |
  | L1 主问题标题 | 120 | 124 | 124 | 158.4 |
  | L2 一句核心判断 | 52 | 54 | 54 | 68.6 |
  | L3 节点标签 | 76 | 78 | 78 | 100.3 |
  | L4 节点短注 | 34 | 35 | 35 | 44.9 |

  - 中英共用 alphabetic baseline，偏移 **0**，不逐字体做 baseline 位移。
  - 块间距 **1.55em**；左右边距 **56px @1080**。长标签先换行或提炼，不压到字号下限以下；不强迫每个节点用满字号。
- **分段**：ASCII 0x20–0x7E（字母、数字、基本标点）只走 Latin 栈；汉字、全角字符、带圈数字 ①② 归中文栈；其余符号由捆绑中文栈兜底。run 拆分后拼接必须与原文逐字一致——尾 run 必须 flush，ASCII 词与空白行尾不得丢字。
- **替代链（有序，仅捆绑家族）**：
  - 中文：仅 `LXGW WenKai`。缺 glyph 先 preflight fail，**禁止**自动回落黑体、无衬线、serif、系统楷体、PingFang 或任意 generic。个别罕字替代须有明确授权、同气质楷书字族真实 QA 并登记，不得自动系统回落。
  - 英文默认链：仅 `Patrick Hand`；`Caveat` 不自动回落或回切。用户显式选用或批准备选入链且 QA 通过时，才允许 `Patrick Hand` → `Caveat`；不允许 generic cursive 或系统手写回退。
- **缺字与兜底**：渲染前用捆绑 cmap 核对选题用字；缺字必须在 style_check 证据中记录（缺哪些字、如何处理）。整段中文落入黑体渲染不达 V2 风格，**不可通过 style_check**。英文栈不含的中文标点、箭头等字形由中文栈承担。
- **许可与核验**：只捆绑许可明确、名称/版本/哈希已核验的字体；不下载无授权文件，不臆造未安装字体；不伪称像素级复刻锚点图。
- **移动端**：390px 宽度真实预览；短注墨迹 ≥9px 是本规范工程基准，不是通用标准。机器只核字体登记、捆绑文件存在性与哈希一致、cmap 覆盖与回退链规则；气质、笔画均衡与可读性由人工渲染核对，脚本不机判 visual，也不验证来源正文属实。

## 短注与条件承接

- 节点短注是关键词，**至多一行**；解释性长句下沉正文，不堆进图面。
- 不设独立页脚脚注、不写口径性小字。
- 关键条件（安全前提、版本边界、适用范围）优先在图内节点或标注表达；图内放不下的由正文承接，但图本身不得因省略条件而失真或改变结论。

## 章节登记与下沉理由

- `source_sections` 全量登记教材与压缩正文章节，不允许靠漏列躲覆盖。
- 不上封面的详细参数、选型对比、成本细节，在 `coverage_na.sections` 写下沉理由：章节标识 + 去向（教材 §x / 正文）+ 不改变封面主结论的依据。
- 必要前提、改变结论的条件、重要失败路径**不得**作为下沉项排除；脚本只查登记闭环与结构，重要性判断由 `semantic_review` / `coverage_check` 语义证据如实承担，不用词匹配冒充语义安全。

## 关键项登记（critical）

- 从真实教材/正文提炼的重要失败路径、改变结论的边界或前提条件，在 manifest 中显式登记：可在对应 `core_points` 上标 `"critical": true`，也可在顶层 `critical_points` 数组列出（条目形状与 core_point 一致：`id / category / source:{doc,section} / summary / maps_to`，双页另带 `page`）。
- 脚本小门（仅 V2）：关键项的 `source` 登记字段合法（`doc` 为 textbook/post、`section` 非空且列入章节清单）、`summary` 非空、`maps_to` 命中有效节点/分区；其 `(doc, section)` 不得出现在 `coverage_na.sections`，关键类别不得仅靠 `coverage_na.<类别>` 理由豁免；缺映射、被 NA 排除、重复 id 一律拒绝。`source` 对应正文是否属实由人工核对，脚本不验证正文内容。
- 空理由不算承接：`coverage_na` 任何 `reason` 必须非空并写明去向与不改变主结论的依据；但脚本不、也不能判断关键清单是否齐全。**哪些分支/条件属于关键项，由 `semantic_review` / `coverage_check` 人工逐点证据确认**，逐条列出判断依据，不用词匹配或“已核对全部”冒充语义安全。
- V1 不设本关键项门；旧四必备类别与全集口径冻结不变。

## 密度与双页

- 过密先做层次提炼：合并同义标签、简化连线、砍解释性短注；提炼后仍出现字号低于可读下限、框体重叠、箭头交叉、安全边距被占，才拆 2 页并列分块。
- 过简到遗漏主线或关键分支，直接拒绝返工，不允许“先出一张简单封面占位”。
- 双页无独立总览页，编号 ①/②，共用一份 manifest / diagram_type / 节点清单；不画跨页长箭头，跨页依赖用页内文字标注。

## 规格与资产

- 1—2 个封面单元，竖版 3:4（参考 1080×1440）；每单元 = 可编辑源 + 预览。
- V2 风格锚点：`assets/cover-anchor-v2.webp`（仅提取版式、线条、色彩、字体气质，不复用旧图技术断言与连线）。
- 渲染后逐节点/箭头/标签核对，缩到手机宽度检查可读性；专名、数字、标签与正文一致。

## 能力边界

脚本可查：单元数量、canvas 比例、双页 page 标注、版本一致性、必备类别、映射落点、章节登记闭环、flow 分支结构。脚本**不**判断：排除理由是否正当、条件是否关键、图面语义是否正确。后者必须有人工逐点逐边走读证据，证据不足不得放行。
